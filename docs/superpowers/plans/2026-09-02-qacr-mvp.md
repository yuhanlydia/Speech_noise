# QACR MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Build a reproducible MVP that tests same-waveform relevance switching and trains/evaluates Query-Conditioned Audio Contribution Routing (QACR) against matched baselines.

**Architecture:** A lightweight `sar` Python package separates data construction, model interfaces, routing math, metrics, and CLI orchestration. Qwen2.5-Omni support is optional at import time so CPU verification can exercise routing mathematics and experiment plumbing. Same-waveform paired manifests are the central abstraction; QACR gates only the audio contribution term.

**Tech Stack:** Python 3.10+, PyTorch 2.2+, pydantic 2.x, PyYAML, NumPy, soundfile, pytest; optional transformers/accelerate/bitsandbytes.

**Spec:** `docs/superpowers/specs/2026-09-02-selective-acoustic-relevance-design.md`

## Global Constraints

- Primary backbone `Qwen/Qwen2.5-Omni-3B`; Talker off; text scoring only.
- 4-bit NF4 where supported.
- Paired use/ignore records must reference identical waveform hashes.
- QACR gates audio-prefill contribution only; text/generated-token state stays untouched.
- Gate=1 reproduces base contribution.
- Primary metrics: IgnoreAcc, UseAcc, SAR, PairSwitchAcc.
- External adapters never silently download benchmark audio.
- No RL, self-distillation, source slots, or learned separation in MVP.

### Task 1 — Schema, mixer, metrics
Create `pyproject.toml`, `src/sar/data/{schema,mixing,relevance_pairs}.py`, `src/sar/metrics.py` and unit tests. Implement strict same-waveform pair validation, deterministic mixing/hash, and hand-verified pair metrics. Run focused tests, then commit `feat: add relevance-pair schema mixer and metrics`.

### Task 2 — Model protocol and canonical scoring
Create `src/sar/models/{base,qwen_omni}.py` and CPU-safe tests. Define `OptionScores`, `RoutingContext`, and `AudioLMWrapper`; keep GPU dependencies lazy. Implement sequence-level option scoring. Commit `feat: add audio LM protocol and Qwen Omni wrapper`.

### Task 3 — QACR math
Create `src/sar/methods/{base,qacr}.py` and tests for identity, text isolation, audio mask, and same-audio/different-query gate switching. Implement

`r_j(q)=sigmoid((W_q e_q)^T(W_a h_j)/sqrt(d_r))`

and gate only masked audio attention contributions. Commit `feat: implement query-conditioned audio contribution routing`.

### Task 4 — Matched baselines
Create static gate, layer router, head router, fixed-KV control, oracle mask, and tests under one routing interface. Expose trainable parameter counts. Commit `feat: add matched routing baselines`.

### Task 5 — Manifest builder and external adapter contracts
Create deterministic JSONL/audio manifest builder plus local-manifest adapters for RSA-Bench, MMSU, SH-Bench, VoxSafeBench. Missing roots must raise actionable setup errors; no auto-download. Commit `feat: add reproducible manifests and benchmark adapters`.

### Task 6 — Training/evaluation/configs
Create strict YAML config loader, routing-only trainer skeleton, paired evaluator, Qwen2.5-Omni-3B NF4 config, method/data/experiment configs, and run scripts. Smoke tests use fake wrappers and never download weights. Commit `feat: add experiment configs training and evaluation CLIs`.

### Task 7 — Documentation and verification
Expand README with research hypothesis, benchmark roles, A4000 setup, commands, metrics, artifacts, and Gate A/B/C stopping rules. Add `.gitignore` and CPU-safe import tests. Run `python -m compileall src scripts` and `pytest -q`. Do not claim real GPU success unless actually executed. Commit `docs: finalize QACR MVP experiment harness`.

## Verification discipline

Every task is test-first: add a failing focused test, implement the minimum behavior, rerun focused tests, then run the relevant broader suite. Final completion requires the full CPU test suite and compile check to pass. The sealed external benchmark stage is not run until Gate A/B/C controlled experiments justify it.
